# Install DevOrbit

Download the installer for your computer from the [DevOrbit Releases page](https://github.com/prasannashrestha011/devOrbit/releases). Under **Assets**, choose:

| Your computer | Download |
| --- | --- |
| Windows | The file ending in `-setup.exe` |
| Mac with an Apple chip (M1 or newer) | The file ending in `_aarch64.dmg` |
| Mac with an Intel chip | The file ending in `_x64.dmg` |
| Ubuntu or Debian Linux | The file ending in `.deb` |

Then install DevOrbit:

- **Windows:** Open the downloaded `.exe` and follow the installer prompts. Launch DevOrbit from the Start menu.
- **Mac:** Open the downloaded `.dmg`, drag DevOrbit into **Applications**, then open it from **Applications**.
- **Ubuntu or Debian:** Open the downloaded `.deb` with your software installer, select **Install**, then open DevOrbit from your apps menu.

Your computer may show a security warning because these development builds are unsigned. Check that you downloaded DevOrbit from the Releases page before choosing to open it.

DevOrbit is ready to use after installation. It sets up its local data when you first open it.
